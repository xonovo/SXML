# Websocket取消订阅

## API说明

取消订阅的方式：

1、关闭客户端与服务端的Websocket连接

2、通过以下API实时取消订阅产品          &#x20;

## 请求频率

同一个Websocket连接，所有的请求（订阅、取消订阅、心跳）限制为**1分钟60次**，如果超出请求频率限制将会自动断连。如果断连次数过多被系统判定为恶意请求将会封禁apikey。请在使用过程中注意调用逻辑。

## 取消订阅-请求

```json
{
    "code": 11000,
    "trace": "423afec425004bd8a5e02e1ba5f9b2b0"
}
```

| 参数名     | 类型      | 必填 | 描述                                                | 示例值                                |
| ------- | ------- | -- | ------------------------------------------------- | ---------------------------------- |
| `code`  | Integer | 是  | 取消订阅的协议号。实时成交明细：`11000`；买卖盘口：`11001`；实时k线：`11002` | 取消实时成交明细订阅协议号：`11000`              |
| `trace` | String  | 是  | 可追溯ID（随机字符串）                                      | `423afec425004bd8a5e02e1ba5f9b2b0` |

## 取消订阅-应答

```json
{
    "code": 11010,
    "trace": "423afec425004bd8a5e02e1ba5f9b2b0",
    "msg": "ok"
}
```

| 字段名     | 类型      | 必填 | 描述                    | 示例值                                |
| ------- | ------- | -- | --------------------- | ---------------------------------- |
| `code`  | Integer | 是  | 取消订阅响应协议号。固定为：`11010` | 固定值：`11010`                        |
| `trace` | String  | 是  | 订阅传入参数可追溯ID           | `423afec425004bd8a5e02e1ba5f9b2b0` |
| `msg`   | String  | 是  | 响应                    | `ok`                               |
